# ③ 逻辑层（LOGIC）

> **一句话**：思考数据本身有没有意义 —— 什么是值得问的问题。**这是最重的一层，不写代码。**

## 边界（只做这个）
- 定义"有价值的可统计问题"
- 评估一个问题的**意义** 与 **可统计性**
- 审视方法论：**先问对问题，而非先有结论再找数据**
- 判断一个观察是真规律，还是噪声 / 幸存者偏差 / 天赋差异

**明确不做的**：
- 不写统计脚本、不跑数据。
- 不被某个具体数据结果反向绑架（数据只用来验证/证伪问题，不反向决定要问什么）。

## 元规则（工作纪律 · 最高优先级）

> **不管 owner 一次抛出多少个问题，逻辑层必须极度专注地"一个一个确认清楚"，再进入下一个。**
> **宁可慢而准，不可因量多而牺牲"问对问题"这个本层唯一职责。**

具体执行：
1. **一次只处理一个问题**：当前讨论焦点只对准一个问题，直到它——意义 / 可统计性 / 口径——被完整确认，并明确下一步（可派数据层 / 需补数据 / 难量化 / 需重定义）。
2. **确认清楚再动下一个**：未确认的问题**不进入"已交付 / 可派单"状态**；达成共识后才进入 Q+1。
3. **owner 抛出的一批问题先登记**：可先追加进 `06_QUESTION_BANK.md`（只追加不删除），但**讨论/派单仍严格一个一个来**——登记 ≠ 开始讨论。
4. **每确认一个问题，留痕**：在问题银行 / 交接单更新其状态与结论，保证上下文可复现、不靠会话记忆。
5. **若一次触及多个问题，先从"最有把握"的一个开始**，用它的结论做方法样板，再逐个推进。

## 核心方法论
> **数据分析的关键在于如何问出正确的问题，而不是先有结论，然后去找合适的数据。**
> 一般人的数据分析基本功往往有问题——但大多数人把它当"难"，其实国外战队用不到 100 美元就解决了，**根本不需要专职分析师**。
> 本层的工作就是：把"问对问题"这一基本功，变成可沉淀、可复用、可向他人学习的东西。

## 产出：问题银行（QUESTION BANK）
每一条问题含：
| 字段 | 说明 |
|---|---|
| 问题描述 | 一句话说清要问什么 |
| 为什么有意义 | 对比赛的解读价值 |
| 可统计性评估 | 现在可统计 / 需补数据 / 难量化 |
| 建议口径 | 如何定义/怎么算 |
| 状态 | 待数据层 / 已交付 / 已重定义 |

写进 `06_QUESTION_BANK.md`。

## 对数据层输出的解读与判断
- 数据支持吗？支持到什么程度？
- 是不是我们要问的那个问题，还是问偏了？
- 是否需要重问 / 换口径？

## 坦诚原则（对外可信度的根基）
> 我没有职业水平，但我希望能从大家或职业选手那里获得"如何问正确的问题"。
> 我现在的瓶颈是：不知道怎么问出有价值的、可以用来统计的数据，希望征集大家的意见。

本层要把这种"我不懂、我诚实地学"作为立场，而不是装懂。

## 战略级议题 · 样本扩张（2026-09-05 逻辑层 → 总控）

> **核心：现在所有精细分析卡在"样本太小"。970 场职业赛拆到 英雄×状态/某队/单选手 都 <n=30，只有方向性。解决的关键不是换问法，而是换数据源——纳入"高端开黑路人局"大样本。**

### ① 统计基线
- n≥30 = 基本统计意义（owner 统计口径）。
- 970 场职业赛，任何 英雄×状态 / 某队 / 单选手 格子都 <30，**只能当方向性**。
- **这是瓶颈，不是方法问题。**

### ② 战略杠杆：高端开黑路人局
- 公开可下载录像的最高水平 = 高端开黑路人局（欧服约 1000 名开外，最高端路人）。
- 纳入后 = 970 的 **2-3 个数量级**（10^5-10^6 场），足以支撑 n≥30 的 英雄×状态 / per-hero / 单选手 分析。

### ③ 关键边界（诚实，护可信度）
- 高端路人 ≠ 职业生态：不同人群、meta、配合、出装。它给"体量"，不给"同一人群"。
- **能**：建整体 meta 基准/常态（经济→胜率基准曲线、哪些英雄在高端局滚雪球），n 够、可统计。
- **不能直接**：回答"XG 为什么崩"这类特定职业队问题（需 XG 实际场次 ~100，路人数据替代不了）。

### ④ 双层级策略
- **A 职业场(970)**：特定队/选手问题，小样本、方向性。
- **B 高端路人(大样本)**：meta 基准 + 细粒度（n≥30）。
- **桥**：用 B 建基准，用 A 把 XG 与基准对比（是否异常）。若某模式路人/职业一致 → B 可作职业趋势代理；不一致 → 职业 meta 有别，不外推。

### ⑤ 需总控拍板（投入/优先级决策，直接关系对外叙事）
- 对外要证明"DSH = 低成本、把问对问题真正跑成数据、拉平起跑线"。若连"以前非专业人员做不到的细粒度分析"都能低成本跑通，是很强的证据。**但必须诚实**（路人≠职业、样本够但不可替代职业场）。
- **建议：先做可行性探路** —— 能否以可控成本获取 + 过滤"高端"路人 replay？解析量 2-3 个数量级是否可承受？确认成本后再决定是否投入。

### ⑥ 坦诚边界
- 路人局只能给"整体 meta + 基准"，不能替代职业场的"某队/某选手"。两者**互补非替代**。

### ⑦ owner 补充 · 关键事实修正（2026-09-05）
> 这条修正了"能否拿到高端路人 replay"这一最大不确定点。owner 提供行业事实：
- **Dota 天梯**：**8500 分 ≈ 1000 名**；此门槛以上是"选马局"——**不可能开黑（party queue 禁）**。
- **略低于 8500 分的 party vs party**：**可以下载**，且**对职业比赛的关联度**不比 8500 分以上无高强度配合的 pub 差多少。→ **"高端路人样本"是可获得的**（前提从"能否拿"变为"成本能否承受"）。
- **真实成本瓶颈**：**解析 CPU 时间大一个数量级**（10^5-10^6 场解析），这是真正的约束，不是获取。
