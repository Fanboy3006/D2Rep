## 2. 维度与指标

**维度**
- 战队（全部队伍，toggle）
- 时间窗：**0-7 / 7-20 / 20+ / 全部**（owner 定；**替换** Q5B 的 -1:30-7 / 7-15 / 15+）
- 滑块：位置出现次数下限 / 值热力上限 / 底图透明度（同 Q5B）

**基础指标（逐格 × 战队 × 时间窗）**
| 指标 | 含义 |
|---|---|
| 假眼出现次数 | 该格出现过的假眼支数（样本量判据） |
| 平均存活时间 | 该格假眼平均存活（沿用"平均"口径，非计数） |
| 出场场次 | 该格涉及多少场比赛 |

**刁钻眼位 toggle（owner 定义，③已确认）**
> **刁钻假眼 = 存活 > 1 分钟，且其存活期间 1200 单位内存在敌方真眼。**
> （真眼真视/反眼半径 = **1050**，用 **1200** 作缓冲。）
- 精髓：把"**刁钻**（近处有真眼却没被反）"与"**本来就安全**（附近根本没敌人）"区分开——这正是"绝对生存时间长"单独用会误判的地方。
- 打开 toggle → 只高亮/统计满足此条件的假眼位置。

## 3. 必须继承的 Q5B 口径（一条都别改）

`STRATEGY/Q5B_WARD_VIEWER.md` §4 五条关键裁定：

1. **判真/假眼 = 实体类名**（`TrueSight`→真眼、无后缀→假眼）。❌ 不可用 combat `inflictor`（`item_ward_dispenser` 真/假都会出）。
2. **放置时刻 = combat `item` 条目的 `t_cle`**；无命中则由实体 `t_tick` 经 `t_tick→t_cle` 映射还原。❌ **禁用 `ward_placed.properties.t_cle`**（恒早 540.26s）。
3. **到期 ⇔ `attacker == target`**；其余一律算"被反"（含同队自毁、中立野怪、小兵/塔）。
4. **到期时刻 = 放置 + 常量寿命**（真眼 420 / **假眼 360**）；死亡事件只用于确认到期。
5. **销毁与眼一一对应**；Death 不带坐标 → 用**实体自身末现 − 9s** 定位，且**每个 Death 只用一次**。❌ 禁止"寿命窗内最早 death"（相邻同队同型眼会互抢）。

§8 已知坑（务必继承）：`entity_index` 会复用（**绝不作主键**）；`ward_placed` 行可能重复（PVS 抖动，按复合键识别）；dispenser 必须靠实体判型；自毁计入被反；中立野怪打死眼；时钟量化；前端坑（`toFixed`/`onmousemove`，见 `INTERACTIVE_MAP_PATTERN.md` §9）；**右侧钻取表必须跟随"时间窗 + 战队"筛选**。

## 4. ⚠️ 前置修复（必须先办）

**刁钻判定 100% 依赖【假眼/真眼存活窗口】的准确性**（"近处有敌真眼却活着"全靠窗口对齐）。

- 最近回传报 **placed↔destroyed 的 FIFO 配对错配**（实例：真眼 16:59 插入，却把 15:39 的反眼归给它，时序倒挂）。
- → **开工前先确认当前脚本用的是哪种匹配**；若不是"**存活窗口 + 半径**"精确匹配，**先修好再算刁钻**，否则刁钻判定全建在错窗口上。
- 注意与 Q5B §4.5（"末现 −9s 一一对应"）对齐，搞清是否为同一处、是否回归。
