# 交接协议（HANDOFF）

> **用途**：层与层之间不靠聊天记忆，靠结构化交接，保证不同会话之间上下文纯净且不丢失。任何一条工作跨层流动时，用这个模板。

## 交接模板

```
问题ID：
请求层：        （①地图 / ②数据 / ③逻辑 / ④总控）
接收层：
目标：
输入（数据/口径/样本）：
期望输出（格式）：
优先级：
截止：
已知约束（缺数据 / 口径风险 / 不可统计原因）：
```

## 使用约定
1. **填写单**：请求方填好模板，附到 `06_QUESTION_BANK.md` 对应问题条目下。
2. **接收方确认**：接单后在模板里回"已接收 + 初步可行性判断"。
3. **完成后回传**：用同一模板填"输出 + 口径说明 + 可复现脚本名"。
4. **不可统计则回退**：接单方若发现缺数据/口径不成立，标注原因并回退请求方，**不硬造结果**。

## 示例
```
问题ID：Q2
请求层：③逻辑
接收层：②数据
目标：XG/VG/TY/PV/TS 五队 10分钟经济胜负平对胜率影响，10-20分钟相对10分钟经济的边际影响
输入：970 场（按 5 队过滤），10分钟/20分钟经济快照 + 胜负
期望输出：分队伍/分时段统计表 + match id 清单
优先级：高
已知约束：需先定义"10分钟经济胜负平"阈值（如 ±1000）
```
