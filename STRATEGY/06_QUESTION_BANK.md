# 问题银行（QUESTION BANK）

> **用途**：所有"值得问的问题"的权威清单，是 ③逻辑层 的产出、②数据层 的输入、④总控 做对外帖子的素材源。
> 每条问题写明意义、可统计性、建议口径。**只追加、不删除**，状态流转：待数据层 → 已交付 / 需重定义。

## 首批问题（来自项目 owner 的草稿，2026-09-05）

### Q1 · 野区经济价值
- **描述**：每一个野区平均多少钱？清空一个野区后，对团队经济的贡献是多少钱？
- **为什么有意义**：量化野区经济价值，辅助"刷野 vs 打团 vs 推塔"的判断。
- **可统计性**：现在可统计（数据层已有击杀/经济解析）。
- **建议口径**：按野区/中立怪统计击杀奖励 + 清野时长；"贡献"= 击杀奖励 + 由此产生的出装/等级差。
- **状态**：待数据层。

### Q2 · 五队分时段经济对胜率的边际影响
- **描述**：XG / VG / TY / PV / TS 这 5 队，10 分钟经济胜负平对胜率的影响？10-20 分钟相对 10 分钟经济对胜率的边际影响？附对应 match ID 和统计表。
- **为什么有意义**：区分"前期经济领先"与"中段滚雪球"哪个更决定胜负，且看队伍差异。
- **可统计性**：可统计（按队分组、分时段、需 match id 清单）。
- **建议口径**：先定义"10 分钟经济胜负平"阈值（如 ±1000）；分时段（0-10 / 10-20 / 20-30）。
- **状态**：待数据层。

### Q3 · 英雄随时间的经济影响力
- **描述**：哪些英雄在 10 分钟对经济是正影响、哪些是负影响？10-20 / 20-30 分钟分别是什么情况？
- **为什么有意义**：识别英雄的"滚雪球/后期"能力，辅助选人与节奏判断。
- **可统计性**：可统计（分英雄、分时段、需控制变量：线/位置/辅助 vs 核心）。
- **建议口径**：分英雄、分时段计算经济差贡献；注意样本量与位置偏置。
- **状态**：待数据层。

### Q4 · 基本功 vs 天赋/注意力（难量化）
- **描述**：XG 对线基本功没问题（基本不退化）；但 y 队有问题——很难说是基本功，更像**天赋上限 / 注意力机制**的问题。
- **为什么有意义**：区分"可训练的基本功"与"难以训练的软素质"，对训练/投资有意义。
- **可统计性**：**难量化**（需先定义可测指标，如"对线经济差随时间的退化率"、失误率、注意力持续度）。
- **建议口径**：先由 ③逻辑层 定义"基本功退化"的可测量指标，才能进入数据层。
- **状态**：待逻辑层定义（先于数据层）。

> **说明**：Q1-Q3 可先做；Q4 必须逻辑层先定义指标。问题银行随讨论持续追加。
