## 本层提问红线（沉淀为可复用资产）

1. **从「决定」出发，不从「结论」出发**：一个问题的答案若不会改变任何后续动作 = 无意义。
2. **先可证伪再求快**：观察必须能转成"能被数据打死"的假设；想象不出能杀死它的数据 = 故事。
3. **先定对比基线**：孤零零一个数字无意义，归因必须有对象（跟谁 / 何时 / 跟"若无此事"比）。
4. **信噪比检查**：信号能被现有数据分辨出来，还是会被噪声 / 幸存者偏差 / 天赋差异淹没？
5. **预注册口径与阈值**：跑数据前写死 公式+时刻+阈值+样本+排除规则，防止"发现异常再定义异常"（挪门柱）。
6. **揪出混杂变量**：见信号先问"是 A 变了，还是 B 变了让 A 看起来变"。时间是最常被忽略的混杂变量。
7. **价值/成本矩阵取舍**：决策价值 × 可统计性 × 归因可信度 排序，别把每条当必做项。
8. **坦诚边界**：把"没这个数据 / 测不了 / 推论超出证据"写进条目，这是对外可信度的根基。

**单元/指标**：
- 单元 = 地图区域（网格 + 语义标签：线/野区/肉山/三角），不再限野点。
- 指标（三视角）：

  2. **绝对队经济**：天辉有人在此区域 → 天辉总经济增量/分钟。
  3. **相对队经济**：天辉有人在此区域 → Δ(天辉−夜魇) 金/分钟（升还是降）。

**关键警告（③，防因果倒置）**：相对队经济指标**有反向因果**——赢的队伍才会入侵敌方富区，"金角"可能是"赢→占富区"而非"占富区→赢"。三视角可辩护度：**GPM > 绝对队经济 > 相对队经济**。相对项需**加条件（同领先/落后状态 或 同时间窗）**或至少标注"描述性、受反向因果影响"。

**口径（建议）**：沿用 250 格网格作区域；每格输出 GPM + 绝对队经济增量 + 相对队经济变化；相对项对"天辉有人在该格"时间窗算 Δ(天辉−夜魇) 金/分钟，并加条件/标注；产出全图经济价值地图 + 复核明细 + match_id。

## Q5 · 眼位价值（【已收敛为 真眼(Sentry) 研究】；假眼 Observer → 另立 Q6）—— 【已派数据层】

- **绝对生存时间**：该眼位假眼的实际生存时长（被反=destroy−place；自然过期=寿命；**到游戏结束仍存活=右删失，需处理**）。

- **相对**：反眼成功 ÷ 附近(100/300/600)平均（百分比）。**高=刁钻真眼位**（这位置反眼远超周围）。
